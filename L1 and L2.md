# Digital Design and Computer Architecture (DDCA)
## Lecture 1 & 2 — Summary Notes



### Overview
These lectures introduce the **basics of digital systems** and how logical circuits are designed using Boolean algebra and logic gates.


# Lecture 1: Introduction

##  Digital Systems
- Use **binary values (0, 1)**
- More reliable than analog systems

## Key Components
- **Transistors** → act as switches  
- **Logic Gates** → perform operations  

##  Types of Circuits
- **Combinational** → no memory  
- **Sequential** → has memory  

##  Important Idea
- Functional correctness + timing both matter

---

# Lecture 2: Combinational Logic

##  Definition
Output depends **only on current inputs** (no memory)

##  Basic Gates
- AND, OR, NOT  
- NAND, NOR, XOR  

##  Boolean Algebra
- Used to represent and simplify logic  
- Key forms:
  - SOP (Sum of Products)
  - POS (Product of Sums)

##  Logic Simplification
- Reduces cost and improves speed  
- Methods:
  - Boolean laws  
  - Karnaugh Maps  

##  Common Components
- **Multiplexer (MUX)** → selects input  
- **Decoder** → activates one output  
- **Adder** → performs binary addition  
- **ALU** → arithmetic + logic operations  

##  Key Insight
- NAND or NOR gates alone can implement any circuit
